本补充材料的组织如下。
\begin{itemize}\setlength{\itemsep}{1pt}\setlength{\topsep}{2pt}
\item \textbf{附录~\ref{app:implementation}}（第~\mainref{sec:method}~节）推导支撑精度分配的误差分解，并给出输入、预测头与损失、动作流，以及在 \bench 与 DROID 上训练的细节。
\item \textbf{附录~\ref{app:benchmark}}（第~\mainref{sec:setup}~节）定义 \bench 的任务与角色、数据与划分、实时执行器与延迟测量、基线与消融对照，以及统计方法。
\item \textbf{附录~\ref{app:results}}（第~\mainref{sec:main_results}--\mainref{sec:principles}~节）报告逐任务结果、其他协议与延迟、DOMINO、按训练种子列出的消融、对位姿噪声的鲁棒性，以及预测诊断。
\item \textbf{附录~\ref{app:real}}（第~\mainref{sec:real}~节）介绍真机装置、跟踪与试验协议，并给出详细结果与失败案例。
\item \textbf{附录~\ref{app:design}} 报告以更小规模选出最终模型编码器、历史、预测目标与耦合方式的设计研究。
\end{itemize}
