### 结果不落在任何预设情况时

开关覆盖了最可能的结局；若出现以下情况，按"分解仍成立、经验结论换一种说法"的方向最小改写，不要回退到"实验顺序"写法：

- **视觉历史也有明显帮助**（例如遮挡任务）：保留"记住"原则，改写为"历史通过运动状态起作用；视觉历史只在策略能从中恢复运动状态时有用"，
  并在附录 G.3"视觉历史"段改为如实报告。
- **SE(3) 历史增益不随延迟增长、或不在 $\ell^\star$ 附近出现**：这是对"领先时长 × 运动"项的直接反证。先检查延迟扫描是否真的推进了物理（附录 B.3），
  再检查跟踪误差是否主导（图 4c、表 S7）；若确实如此，把 5.3 的表述改为"增益主要来自 $e_{\rm loc}$ 或方向歧义"，并在附录 A.7 说明。
- **坍缩图（图 4a）不成立**（不同任务/速度的点不落在同一曲线上）：如实报告 Spearman $\rho$，把"预测每个策略在何处失败"弱化为"预测趋势方向"，
  并检查 $\varepsilon$（表 S4）是否估计偏差。
- **SE(3) 未来不优于点轨迹**：把"目标需要 SE(3)"弱化为"目标需要度量化、足以确定接触点的表示"，SE(3) 作为其紧凑形式；Kabsch 拟合行（表 S13）可支撑"刚性先验"的说法。
- **在线读取预测反而有害**：选 `\QthreeCase{3}`，并在 5.3 "行动"段说明原因（预测误差通过 $\mathcal F\to\mathcal A$ 传播；引用表 S11 的干预）。
- **区间跨越实际意义阈值（模棱两可）**：用"在本设置下未观察到可区分的差异（$\Delta$ = x，95% 区间 [a, b]）"，不要写"相当"或"更好"。

## 3. 填数工作流

占位符有三种，编译后的 PDF 中都以品红色显示：

- 文本：`\fillin{...}`（方括号内为提示，如 `XX.X`、`name`、`values`、`confirm`）。
- 表格：`\resultplaceholder`（品红色破折号）。破折号按典型数值 `00.0` 的宽度占位，因此当前表宽和版面已接近填数后的样子；
  格式更宽的列带有模板，如 `tables/supp_per_task.tex` 差值区间列的 `\resultplaceholder[{+00.0 [00.0, 00.0]}]`、
  `tables/supp_real_ci.tex` 的 `\resultplaceholder[00.0 {[00, 00]}]`、`tables/supp_predict.tex` 位姿误差列的 `\resultplaceholder[{00.0/0.0}]`。
  填数时把整个占位（连同方括号模板）替换为数值。
- 图：`\figplaceholder`（品红边框的方框，内写详细规格）。

生成待填清单（按文件、行号列出每处待填的提示、它前面的原文和所属的开关分支，另列图占位与每张表的待填格数）：

```powershell
python scripts/list_fillins.py --markdown tmp/fillins.md        # 英文
python scripts/list_fillins.py --zh --markdown tmp/fillins_zh.md # 中文审读稿
```

规则：

1. **同一数字在三处一致**：表格 → 正文 → 中文稿同一位置。`scripts/check_build.py` 会报告中英文之间的数字差异，以及开关分支、待填项、标签、引用和表格不对应之处。
2. **单位与格式**：成功率保留一位小数并带 `\%`；差值写"points / 个百分点"；区间写 `95\% interval [a, b]`；
   时间写 `\,ms`；表中最佳值加粗（`\textbf{}`）。
3. **只填当前开关选中的分支**。未选分支里的 `\fillin` 不会出现在 PDF 中，但 `list_fillins.py` 会列出（它扫描源码）；切换开关前先把对应分支填好。
4. **图**：把 `\figplaceholder[...]{...}{...}{...}` 整段替换为 `\includegraphics[width=...]{figures/xxx.pdf}`，保留原来的 `\caption` 与 `\label`；
   图注中的 `\fillin` 一并填写。
5. **表宽与公式宽度**：填数后重新编译。`preamble.tex` 已把 cvpr.sty 默认的 30pt 溢出容差改为 0.5pt（只影响警告，不改版面），
   因此任何超出栏宽的表格、公式或文字行都会出现在日志里，并由 `scripts/check_build.py` 报告（`--strict` 时报错）。
   超宽时先缩短列名或减小该表的 `\tabcolsep`，不要把表格字号缩到 7pt 以下。
6. **正文页数**：`check_build.py` 同时检查正文止于第 8 页、且正文的图表没有被推迟到第 8 页之后（`late_floats`）。
7. 投稿前：

```powershell
./scripts/build.ps1 -Check
python scripts/check_build.py --final --strict   # 任何待填格、待填文本、超页、推迟的浮动体、未定义引用都会报错
```
