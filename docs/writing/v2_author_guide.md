**一句话主张。** 动态操作的指令必须与它生效时刻的场景相符。\ours 为指令生效的时刻预测场景：记住目标的度量运动，
精确预测目标的 SE(3) 轨迹、粗略预测全场景的 3D 流；预测只用于训练监督，部署时动作读取摘要 token。误差分解（式 3）只作为方法的**动机**，

### 必须先确认的风险：DreamVLA 与实时协议

方法论文的前提是主结果领先。按 Research 开发集的**同步**评测，DreamVLA 约 80%，SE(3)-WAM 约 64–67%。
正文主结果写的是**实时协议**下的领先，而正式实时重评尚未完成。主结果段中"暂停物理"一句已写成中性（`\fillin{name of the strongest paused baseline}`
与 `\fillin{$\pm$X.X}`）：若暂停协议下 \ours 也领先，可改写为"its advantage does not come from speed alone"；若 DreamVLA 领先，
改写为"... leads by X.X points, so part of the gain of \ours comes from its speed"，并在结论中保留"大模型在场景静止时更强"的表述。
若实时协议下也不领先，方法论文结构不成立，需要重新讨论论文定位（见 2026-10-22 对话）。

## 2. A4 的实验承诺与结论边界

2026-10-23 已决定最终 24×1024 配方只新增四个核心对照，每个三个训练种子，暂不补 R5。完整模型的参考结果复用 A1。四个对照共12次新增训练，优先总64卡并行四路16卡任务；实际运行由 Research 实验主文档维护。

| 对照 | 唯一改变 | 保留内容 |
|---|---|---|
| 无目标运动历史 | 去掉过去目标位姿、速度与加速度 | 当前图像、当前目标位姿、八个机器人状态、全部损失 |
| 无未来监督 | 关闭SE(3)、场景流/可见性、未来Depth/DINO/dynamicRGB损失 | 当前目标RGB重建、动作损失 |
| 无场景流监督 | 只关闭场景流与可见性损失 | 专用SE(3)、全部外观辅助 |
| 无专用SE(3) | 只关闭目标位姿预测损失 | 14²全场景流、全部外观辅助 |

场景流本来就覆盖目标、机器人与环境。无SE(3)是统一粗粒度流对照，不新增32点目标轨迹头；无流测量场景流监督的作用，不能归因为只去环境。所有消融都需要按对应目标独立训练；只在推理屏蔽历史或预测头不能代替训练消融。

评测仅要求C实时协议下附加0/150 ms，四面板与逐任务结果复用同一批轨迹。预测头开关只检查固定输入和噪声下的动作一致性与额外计算；C协议下额外延迟会改变闭环，不能据此写成功率相同。

广泛history、representation、encoder、backbone和coupling选择保留为实际四层筛选，注明来源组、编码器、学习率日程、种子和数据划分。HISTORY1/FUTURE0各单种子，且日程不同；Q3和BACKBONE0各三种子；AUX0新增外观条件为单种子。旧P09是2D目标轨迹，不是最终24层的统一3D流对照。

当前宏 QtwoCase/QthreeCase/BackboneCase 仅保留既有显示与设计选择功能。不能通过切换宏，把未运行的网格/耦合实验变成已验证结论，也不能根据旧的“预期结果”模板选择最终结论。最终模型保持14²流、训练监督与共享注意力；不声称24层训练监督与R5等效、粗网格与28²/56²等效或几何优于外观。

正文填入带符号差值与区间，保留零效应和负效应。若核心对照没有支持某项贡献，收窄对应引言/结论，不把差异不显著写成等效。A7 已删除分辨率×间隙扫描、额外CV/CA训练组合和未完成干预矩阵；旧静止历史干预与预测筛选按原实验规模保留。

A7 保留 DOMINO 的四方法比较：本文方法、π0.5、DynamicWAM、PUMA；移出 LIBERO 外部评测。主表两个＋SE(3)基线和CV输入仍需各自匹配训练，不能用原基线或A4无未来监督端点替代。目标运动输入相同仍不代表深度等全部输入相同。离线预测优于CV/CA只说明读出质量，策略收益需由闭环对照支持。

A8 已确定完整模型与CV-input各三个训练种子，DOMINO四方法各一个种子、每任务每方法50场；内部五次新增训练优先。具体任务范围、执行顺序与复用见[实验计划](../EXPERIMENT_PLAN.md#a8训练补齐与评测预算)。种子数是已批准预算，填数仍需核验完整训练端点；报告各seed结果与跨seed波动，场景配对区间不替代训练重复。

## 3. 填数工作流

占位符有三种，编译后的 PDF 中都以品红色显示：

- 文本：`\fillin{...}`（方括号内为提示，如 `XX.X`、`name`、`values`、`confirm`）。
- 表格：`\resultplaceholder`（品红色破折号）。破折号按典型数值 `00.0` 的宽度占位，因此当前表宽和版面已接近填数后的样子；
  格式更宽的列带有模板，如 `tables/supp_per_task.tex` 差值区间列的 `\resultplaceholder[{+00.0 [00.0, 00.0]}]`、
  `tables/supp_real_ci.tex` 的 `\resultplaceholder[00.0 {[00, 00]}]`、`tables/supp_predict.tex` 位姿误差列的 `\resultplaceholder[{00.0/0.0}]`。
  填数时把整个占位（连同方括号模板）替换为数值。
- 图：`\figplaceholder`（品红边框的方框，内写详细规格）。

生成待填清单（按文件、行号列出每处待填的提示、它前面的原文和所属的开关分支，另列图占位与每张表的待填格数）：

```powershell
python scripts/list_fillins.py --markdown tmp/fillins.md        # 英文
python scripts/list_fillins.py --zh --markdown tmp/fillins_zh.md # 中文审读稿
```

规则：

1. **同一数字在三处一致**：表格 → 正文 → 中文稿同一位置。`scripts/check_build.py` 会报告中英文之间的数字差异，以及开关分支、待填项、标签、引用和表格不对应之处。
2. **单位与格式**：成功率保留一位小数并带 `\%`；差值写"points / 个百分点"；区间写 `95\% interval [a, b]`；
   时间写 `\,ms`；表中最佳值加粗（`\textbf{}`）。
3. **只填当前开关选中的分支**。未选分支里的 `\fillin` 不会出现在 PDF 中，但 `list_fillins.py` 会列出（它扫描源码）；切换开关前先把对应分支填好。
4. **图**：把 `\figplaceholder[...]{...}{...}{...}` 整段替换为 `\includegraphics[width=...]{figures/xxx.pdf}`，保留原来的 `\caption` 与 `\label`；
   图注中的 `\fillin` 一并填写。
5. **表宽与公式宽度**：填数后重新编译。`preamble.tex` 已把 cvpr.sty 默认的 30pt 溢出容差改为 0.5pt（只影响警告，不改版面），
   因此任何超出栏宽的表格、公式或文字行都会出现在日志里，并由 `scripts/check_build.py` 报告（`--strict` 时报错）。
   超宽时先缩短列名或减小该表的 `\tabcolsep`，不要把表格字号缩到 7pt 以下。
6. **正文页数**：`check_build.py` 同时检查正文止于第 8 页、且正文的图表没有被推迟到第 8 页之后（`late_floats`）。
7. 投稿前：

```powershell
./scripts/build.ps1 -Check
python scripts/check_build.py --final --strict   # 任何待填格、待填文本、超页、推迟的浮动体、未定义引用都会报错
```
