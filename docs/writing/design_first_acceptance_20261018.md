# 完整成稿的验收与停止条件

本轮目标：完成可填入实验数字的论文，而非实验进展报告。正文按八页规划，参考文献另计；提供独立英文补充材料、英文合并版和中文全文。未执行实验不阻塞写作验收，文稿不把预设结论当作实验事实。

## 成稿条件

1. **故事闭合**：动态操作的问题、信息组织原则、Q1–Q3、模型构造、机器人数据预训练和系统评测组成同一论证。贡献覆盖 benchmark、设计研究和完整模型方案，不以已完成工作的数量组织文章。
2. **设计闭合**：明确输入与时间坐标、历史编码、未来表示、参数共享、访问边、生成顺序、训练目标和部署程序。候选选择由明确的开发集与成本约束规则定义，不把“待设计”藏在模型名称中。
3. **实验闭合**：系统比较、Q1–Q3、组合确认、预训练/规模、延迟和外部迁移均有比较对象、控制量、评价指标、数据划分、重复与结果位置。附录给出复现所需细节。尚缺测量只留数值单元格，不写成待办列表。
4. **证据准确**：保留实测结果及其条件；不同训练配方、信息轨道与开发/测试划分清楚可辨。新增协议是本文的设计，不能表述为已经运行的实验；不预写未知的改进方向、显著性、最优配置或因果结论。
5. **读者体验**：英文正文和附录均为连续、完整的论文文本；中文与英文的方法、数字和结论一致。去掉重复辩护、工程进度和内部任务口吻，保留影响解读的必要限定。
6. **图表与版式**：图表各自回答一个问题；流程图覆盖本文方法；主表承担核心比较、附表承担完整展开。正常阅读尺寸可辨，图例/轴/单位/条件齐全，正文八页且无裁切、未定义引用或表格溢出。

## 独立评审与停止

- 全新审稿 agent 不参加写作、不沿用旧稿评分。读取实际 CVPR 参考论文与补充材料，并检查本稿渲染页。至少使用 CoT-VLA、SimLingo 或相同定位的 CVPR 论文比较问题引入、方法表达、实验组织和图表密度。
- 向审稿人提供遮蔽结果数字的稿件与参考材料；任务是判断是否仍能仅凭缺漏、报告口吻或表达粗糙辨认出本稿。该比较是编辑质量检验，不宣称完成真实双盲来源识别实验或保证录用。
- 每项给出 PASS / REVISE 和可定位的理由。仅缺数字、尚未执行已定义协议、结果不积极，不构成写作不通过。
- 出现方法/实验设计空洞、无依据事实、主文/附录矛盾、明显低于参考的图表或排版，均须修订。修订后同一审稿人复核具体问题；必要时增加全新终审。
- **停止条件**：六项均 PASS，无尚未解决的重大或中度表达/完整度问题；编译及中英文事实核对通过。达到条件即交付，不为填数启动实验，不以无限增补实验代替写作完成。
