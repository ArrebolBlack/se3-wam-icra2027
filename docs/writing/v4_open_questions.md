**实现核对（2026-10-24）**
- benchmark [222c3f01](https://github.com/ArrebolBlack/se3-wam-dynamic-benchmark/commit/222c3f01) 的执行器以50 ms为周期，在上次推理结束时或之后的首个边界采用新块，并以新观测发起下一查询。首块未到或旧块耗尽时保持手臂目标和夹爪，不重复积分增量。
- 每次查询回放该方法在RTX 5090上实测的延迟样本；每轮30次预热、300次测量，共三轮，本文方法FP32。评测机器墙钟耗时不决定物理时钟；撞击后任务另保留原生50 ms指令延迟。
- Paused只暂停内在推理时间，附加延迟仍推进物理；Equal latency使用本文方法p95；Original必须有各方法原生执行路径。附加延迟固定0/50/100/150/200 ms。
- 超期为查询出动作时间严格超过50 ms，包含首轮在内的全部查询；动作时龄为实际执行减观测采集，仅保持目标的周期不计策略动作时龄。
- 模型已有`external_realtime`导出与逐tick因果观测路径。历史训练配置保留原值，正式C评测须显式以此模式导出，避免再叠加内部执行器。
- 接触指标使用首次物理接触；两项放置取所持物体接触目标容器，`t3_phase`无接触误差。SR覆盖14任务，接触误差覆盖其余13任务。独立固定机器人参考仅关闭机器人—目标碰撞，保留环境碰撞与正式策略物理。
- 原始验证、延迟样本和正式重评进度由[INFER0](https://github.com/ArrebolBlack/se3-wam-research/blob/main/docs/experiments/INFER0/INFER0.md)维护；接口验证不代替完整重评。未完成端点和结果继续留空。

### A6. 真机位姿标签与在线跟踪（完全无标记最小方案已决定，待实现与验证）

- **已决定**：用户选择完全无标记；在线位姿估计、离线训练标签及误差测量均不使用标记辅助。不将标记辅助作为默认备选。
- **现状**：[POSE0 最新结论](C:/workspace/se3-wam-research/docs/experiments/POSE0/POSE0.md#本阶段结论尚无通过验收的固定物体系训练标签路线) 尚无通过验收的固定物体系训练标签路线。WildDet3D 转换器输出 box frame；固定参考＋FP++ 候选在真实离场重入中失败。在线实时跟踪器、丢失恢复及时间对齐的部署实现仍待完成。
- **最小路线**：按完全无标记方案推进，每实例一次固定参考；离线采用无标记 RGB-D／多视角配准和人工复核，在线优先验证固定参考的因果 RGB-D 跟踪。球类保留固定球心和尺度定义，不要求恢复完整朝向。第二视角、参考采集质量及现场误差尚未验证，具体跟踪器仍由小试确定。
- **输入与标签**：训练策略输入由部署跟踪器因果回放得到，离线监督可用多帧优化；两者共享固定原点、轴、尺度和实例身份。人工复核、重投影一致或两个估计器一致均不能直接当作独立姿态真值。实际误差标定需要明确无标记参照及其测量不确定度。
- **球体旋转已决定**：不开展球体旋转可观测性研究；球类真机目标屏蔽旋转及其历史增量、角速度和角加速度输入，并屏蔽未来旋转监督和旋转误差统计，保留可靠平移及线速度／线加速度。该范围不改变机器人旋转动作、其他任务所需朝向或仿真完整 SE(3) 主线。当前代码尚无对应分量有效性处理，需要实际实现和验证；不得用恒定旋转作为监督，也不得通过丢弃整个位姿同时丢掉可靠平移。
- **论文现状**：§3.2 保持因果 RGB-D 跟踪的通用描述，附录 A.2 的跟踪器及表 S-tracker 的实测数据仍待填写；具体候选应按现场验证更新，不能把 WildDet 的 box frame 当作固定 body frame。
- **下一步**：实现球类目标分量有效性并验证平移保留、旋转屏蔽及机器人动作不变；结合 A5 前20条示范的小试，检查非对称刚体的位姿、球体的平移、缺失恢复及完整感知—策略延迟，不增加整套跟踪器排名实验。具体跟踪器、参考视图数量、丢失阈值和因果时间对齐规则由小试确定。
