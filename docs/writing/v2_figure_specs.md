# v4 图规格：每幅图回答什么、画什么、数据从哪来

尺寸按 CVPR 双栏模板：通栏宽 6.875 in（17.46 cm），单栏宽 3.25 in（8.26 cm）。字号以最终尺寸计 7–9 pt，
主曲线 1.2–1.6 pt。颜色沿用全文语义色（定义在 `preamble.tex`，与 [写作与画图指南](cvpr_ai_writing_figure_guide.md) 一致）：

| 语义 | 颜色 | 用途 |
|---|---|---|
| 观测/历史 | `#0072B2`（蓝） | 过去的 SE(3) 位姿、观测帧、历史相关曲线 |
| 预测/世界 | `#E69F00`（橙） | 预测的目标 SE(3)、环境 3D 流、世界分支 |
| 动作 | `#7B61A8`（紫） | 指令、夹爪路径、动作分支 |
| 真值/中性 | `#4D4D4D`（灰） | 真值位姿、坐标轴、视觉历史等对照组 |
| 失败标注 | `#D55E00`（红橙） | 失败原因、反应式策略的错误落点 |

在统计图里颜色表示**方法族**（或任务族）并在各面板间保持一致；不要让同一颜色在同一图中同时表示方法和时间。
所有统计图只用真实数据；占位框里的"预期趋势"只是画图说明，不能画成示意曲线放进论文。

替换方式：把源码中的 `\figplaceholder[...]{宽度}{标题}{规格}` 整段换成 `\includegraphics[width=宽度]{figures/文件名.pdf}`，
保留 `\caption` 与 `\label`。占位框高度就是版面预算：真实图替换后须重新编译确认正文页数和浮动体。
可编辑工程可沿用 `figure_projects/`（PPTX）或 `figures/` 中的 SVG 脚本。

## 图 1 首图：在未来 4D 场景上行动（`sections/teaser.tex`）

- **回答的问题：** 动态操作为什么要"在动作生效时刻"思考，SE(3)-WAM 给动作提供了什么，以及这带来什么可测的好处。读者只看这张图也应能说出全文主张。
- **尺寸：** 通栏，高 1.65 in（占位高度即预算）。位于首页标题下方、摘要之上。
- **(a) 左侧约 62%：真机传送带抓取照片**，取动作块刚发出的那一帧。叠加：
  - 蓝色小坐标轴：因果跟踪器给出的过去 SE(3) 位姿（−350…0 ms），越旧越淡；
  - 橙色坐标轴：在各指令生效时刻的目标 SE(3) 预测，首个生效时刻 $\tau^{\rm a}$ 处加粗；
  - 浅橙色箭头：只在 `\cfgContextGrid` 网格点上的环境 3D 流——**只画稀疏的几十个箭头**，强调"环境粗"（`\QtwoCase=3` 时按选定网格画）；
  - 紫色曲线：夹爪的指令轨迹，与目标在 $\tau^{\rm a}$ 相遇；
  - 灰色虚影：采集时刻观测到的目标位姿；红橙色虚线箭头：反应式策略会在何处合拢（"抓空"的位置）；
  - 图像下方一条细时间轴：采集 $\tau_t$ → 延迟 $\ell_t$ → 生效 $\tau^{\rm a}$。
  - 部署时跳过预测头：橙色叠加取自训练时的世界头离线计算，图注已自动说明。
- **(b) 右侧约 38%：** 上：图像空间 WAM，"未来帧或隐变量"（胶片条示意）；中：SE(3)-WAM，"目标用 SE(3)、环境用 3D 流、按生效时刻索引"（坐标轴 + 稀疏箭头）；
  下（**必需**）：SE(3)-WAM 与最强基线的成功率随附加延迟（0–200 ms）的变化，数据取自延迟扫描表（`tables/supp_latency.tex`）的两行，与表 1 的 0/150 ms 两列一致。
- **数据来源：** 真机日志中该次试验的跟踪位姿、预测与指令（与相机标定一起投影到图像上）。照片不修饰，叠加内容必须来自日志。
- **图注：** 已写好主张句；替换后补一句该次试验的速度、延迟与结果（例如"0.3 m/s，附加 100 ms 延迟，成功"）。

## 图 3 在物理时间中行动的三个后果（`sections/method.tex`，复用 `figures/interaction_timing.pdf`）

- **现状：** 复用 v1 的概念示意图（裁去顶部标题行，宽 0.76 栏宽），标签已按新符号改过（`figures/generate_figures.py`）。三个面板对应三条原则：
  (a) 同一当前位姿、不同运动 → 记住；(b) 同一生效时刻、不同位姿（平移与旋转）→ 预测/行动；(c) 末端坐标系 $E$ 与目标 $O$ 在 $\varepsilon$ 内对齐，环境只通过间隙 $m\gg\varepsilon$ 起作用 → 按角色分配精度。

## 图 2 SE(3)-WAM 结构（sections/method.tex）

- 当前模型有场景S、摘要M、动作A三组token；掩码为S→S、M→S/M、A→M/A，行表示读取方。
- 当前图像加目标/机器人历史进入场景；摘要承载共享表示，动作流做条件流匹配。SE(3) 与当前目标 RGB 从摘要读出，场景流和未来外观从 patch token 读出；预测头只在训练/诊断中计算。
- 预测不回流给动作；不新增未来查询，也不画领先时长嵌入。场景流覆盖目标、机器人与环境，不画成只覆盖障碍物。
