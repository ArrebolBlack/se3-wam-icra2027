# 图项目目录约定

从 [图项目索引](INDEX.md)选择 Fig1–Fig6。每张正文图只在对应目录维护：

- `figure.tex` 与 `figure_zh.tex`：英文、中文图体、图注与标签；正文通过 `\input` 引用。
- 当前 SVG、TikZ、PPTX、绘图脚本与导出图放在本项目；有外部素材时放在项目的 `assets/`，相关数据与来源说明随图保存。
- `archive/`：被替代的版本，按原主题命名子目录，保留可编辑源、所需资产与来源说明；不作为正文当前图。
- `INDEX.md`：只路由当前图源、资产和历史入口，具体图规格由图源中的占位说明拥有。

替换图时保留图号、标签和中英文对应关系。共享素材只维护一份并从使用项目引用；归档脚本的构建入口仍为 `python scripts/build_figures.py --only <名称>`。
