# 图 S1 执行回合与预测

[论文图体](rollouts.pdf)供[英文稿](../../appendix/real.tex)与[中文稿](../../zh/appendix/real.tex)共用。

图中八行取自[图 4 的专家回合](../Fig4/sources.json)。底图为原生 agentview 的 1024 × 1024 Blender 渲染，叠加来自相同回合的仿真记录。每列的时间点由任务进程决定。

| 任务 ID | 帧时刻（ms） |
|---|---|
| `t1_belt` | 350, 1150, 1900, 2500, 2900 |
| `t1_so3` | 350, 1100, 1600, 2050, 2500 |
| `t1_occ` | 350, 1500, 1950, 2500, 2900 |
| `t2_se3` | 350, 2650, 3550, 4250, 4450 |
| `t3_full` | 350, 1200, 16100, 22150, 25550 |
| `t5_replan` | 350, 1450, 2350, 3900, 4400 |
| `t4_sphere` | 350, 600, 800, 950, 1350 |
| `t4_can` | 350, 600, 750, 1100, 1850 |

流箭头使用 400 ms 的真值轨迹，投影后以起点为中心将位移统一放大 3 倍。目标路径及末端轮廓取最长 800 ms 的记录。小球和罐体使用 400 ms，完整导线穿越使用 6 s。接近回合结束的帧画到最后一个记录状态。导线的坐标轴绘制在中段弯折处。
