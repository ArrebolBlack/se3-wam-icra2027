# 以 TinyVLA 为主参考的 Fig.1 精修

读者应在同一坐标系中看出 FoveaWAM 的成功率与时延位置。主参考 [TinyVLA](https://tiny-vla.github.io/) 由华东师大、美的等单位合作，Fig.1 以时延和平均成功率定位模型，以气泡直径表示参数量。该图提供本图的整体表达与主次层级参考。

## 具体借鉴

- **TinyVLA Fig.1：** 将多项优势集中到一个视觉整体，暖色突出本文模型，直接标注方法名，数字与重点模型靠近放置。当前图保留单一斜向比较，不再把优势拆成两套箭头。
- **Faster-WAM Fig.1(b)：** 同一张图比较 WAM 与 VLA，低饱和对照、直接标签和轻网格保证重点清楚。本图以灰色对照和红橙色主方法保持主次。
- **TurboWAM Fig.1(b)：** 用位置和标签表达方法关系、主方法用少量强调色。这里不逐个方法分配鲜艳颜色，也不额外加入装饰区块。
- **DeeR-VLA Fig.3、Fast-WAM Fig.4：** 对成本与任务表现的联合表达提供补充参照。两图分别使用 FLOPs 和实际完成时间，不能作为推理 p95 的数值依据。

## 上一版精修

恢复原版的一个斜向箭头、红橙／灰色层级与绘图区位置，撤回正交箭头及新增的 +29.9 pp 标注。局部精修只包括：主方法名略放大、星形更清楚、π 下标使用可编辑 SVG tspan、SE(3) 标签和对应引线抬高以避开 ACT 点，以及方法名、轴标题的字号微调。

两个坐标轴及十个点的数据和位置与修改前版本一致；仍从 `tables/main_results.tex` 读取 Native SR、p95。≈10.0× 来自 OpenWAM-α 的 151.7 ms / FoveaWAM 的 15.1 ms，斜箭头是比较方向，文字只报告时延比。各自部署输入和设置由主表说明。

TinyVLA 使用参数气泡和断轴；本图继续以形状区分方法族，保持已选定的线性 0–200 ms、0–100% 视图。未新增参数量口径，也未改变已有 OpenWAM-α (off) 的显示选择。左侧真机场景、几何和叠加标注保留。
