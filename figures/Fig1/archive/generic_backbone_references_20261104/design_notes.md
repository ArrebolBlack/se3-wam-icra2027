# Fig.1 右图：参考取舍与落地

这张图要让读者同时读出成功率与出动作时延。当前数据来自主表，各点是不同方法的 Native SR 与原生 p95；应按真实坐标比较，不把方法类别画成任意概念象限。

## 从原图借用什么

以下是查看[独立原图](INDEX.md)后的设计判断，不是源论文对绘图规范的声明。

| 参考 | 原图中的设计关系 | 本图采用的部分 |
|---|---|---|
| **EfficientFormer Fig.1**（主参考） | 时延横轴、准确率纵轴；方法名称直接靠近数据；主方法具有明确颜色重心 | 保留左上方向的双重优势，分离拥挤标签，以短引线连接真实数据点 |
| **FastVLM Fig.1**（标注参考） | 水平加速箭头只解释时延比；标签水平放置 | 将原来的长斜箭头改成水平时延标注，另用垂直区间表达 SR 差值 |
| **RepViT Fig.1**（层级参考） | 自身方法较强的实线与颜色，对照用更轻的线型 | 红橙色强调 FoveaWAM，方法族用低饱和颜色和形状共同编码 |
| EfficientNet Fig.1 | 多条方法族曲线与直接标注，性能—模型大小的共用坐标比较 | 学习主次层级；不复制其中的图内表格，也不把模型大小解释为实测时延 |
| DeiT Fig.1 | 吞吐量—准确率；同一系列的点以线型联系 | 学习图例与点形的冗余编码；本图仍用线性毫秒轴，不改成对数吞吐量 |
| MobileViT Fig.2 | 两个准确率轴，旁列 Better／Smaller 的局部比较 | 数值标注写明指标与参照；不照搬较重的说明框，也不额外加入参数量编码 |
| MobileOne Fig.1 | 全局与局部比较、直接标注，独立面板容纳不同尺度 | 优先调整标注布局；保留既有 0–200 ms 视图，不加第三个放大面板 |
| FastViT Fig.1 | 移动端、GPU 分面；轴标题说明指标方向 | 保留准确的 p95 time-to-action 名称与单位；不混用不同硬件的测量 |

## 当前落地

- 横向箭头：OpenWAM-α 的 151.7 ms / FoveaWAM 的 15.1 ms = 10.046…，显示为 **≈10.0× faster**。
- 纵向箭头：76.0% − 46.1% = **+29.9 percentage points**，显示为 **+29.9 pp**。中英文图注明确二者均相对 OpenWAM-α，采用各自原生部署设置。
- 反应式策略、VLA、Video WAM 分别用圆、三角、方形及对应族色；FoveaWAM 用星形。π 的下标保持可编辑。
- 标签按局部空间单独排布，引线避开文字。密集的 π 配置保留真实坐标，未抖动或移动数据点。
- 保留横轴 0–200 ms、纵轴 0–100%、全部原先选中的 10 个点，以及既有 OpenWAM-α (off) 排除项（466.3 ms，超出选定视图）。未新增筛选、平滑或误差条。
- ACT 的时延仍低于 FoveaWAM，因此不加“全面支配所有基线”的色块或虚构 Pareto 曲线。Native 部署输入与设置的差异由主表说明，未改写为受控机制证据。

完整 Fig.1 仍为 6.875 in 宽；左侧场景的位置、尺寸与内容保留。右图主方法标签约 6.8 pt，独立 3.25 in 输出中约 8.7 pt。独立右图保持纯矢量、可搜索文字，完整图仅左侧原有点云为位图。

## 重建与检查

在 `figures/Fig1/` 运行 `python build_fig1.py`，再运行 `node render_fig1.mjs`，同时生成完整首图与 `native_tradeoff` 独立图的 SVG、PDF 和 PNG。数据与排版检查沿用 `layout_report.json`；参考裁图由 `collect_references.py` 与 `sources.json` 重建。

验收检查真实数值与线性坐标映射、倍率／百分点、文字与标记的避让、画布边界、PDF 字体与矢量对象、左图像素一致性，并查看 PDF 实际渲染及论文宽度的预览。没有把主观审美判断表述为获奖或录用保证。
